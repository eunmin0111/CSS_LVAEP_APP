# LVAEP Tutor Hub

Open `index.html` in a modern web browser to use the application. No installation, account, or server is required.

The example experience includes tutor Maya Rodriguez, students Jordan Lee and Amina Hassan, a complete September 2026 monthly report, and sample homework assignments. Data is stored locally in the browser, so tutors can add sessions for any month, assign homework and credits, update achievements, download and print monthly reports, and submit end-tutoring or report-review requests without losing changes on refresh. A report is automatically added to the archive whenever a held session is logged in a new month.
